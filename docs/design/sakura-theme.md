# 星铃值班室 · 萌化主题设计提案

供评审。基线为 v2.3.0 本地提交 29855db。建议作为外观设置中第四个可选主题。

## 视觉语言

值班员的识别特征为紫发、猫耳通讯耳机和金色铃铛。解锁页展示半身立绘，展开的侧栏底部展示小头像，窄窗口优先保留菜单。导航选中态用淡紫票签，当前标签带星铃标记。正文沿用应用字体，地址、日志、指标和命令保留等宽字。人物、纸纹和装饰只出现在留白处。

| 用途 | 建议色 |
| --- | --- |
| 页面底 / 卡面 | 奶油白 #FAF6F3 / #FFFCFA |
| 正文 / 主操作 | 墨梅 #332B40 / 深藤紫 #705498 |
| 选择底 / 装饰 | 雾藤 #EEE6FA / 樱粉 #F3C4D4 |
| 正常 / 待处理 / 故障 | 松绿 #36735E / 琥珀 #855A19 / 胭脂红 #AA3851 |
| 终端底 / 输出 | 夜紫 #211D2A / 米白 #F1ECF4 |

## 按工作场景落地

| 界面 | 设计与交互 |
| --- | --- |
| 解锁、应用外框、导航 | 解锁页立绘靠侧，密码框独立；侧栏选中项呈票签状，收起后保留现有图标。 |
| 总览、服务器、实时监控 | 卡片采用细描边，告警整卡红色呼吸并带三角标。图表和多盘图例单独配色，悬停读数清晰可见。 |
| SSH、容器终端、AI、预设侧栏 | 夜紫底终端提供完整 ANSI 色板、光标和选区。标签页、缩放胶囊、AI 建议与接管状态使用同一组控件；接管有清楚的文字标记。 |
| 文件管理、编辑器、搜索、传输中心 | 文件区保持原有行高；传输浮球为星铃圆章，进度环表达完成比例，展开后显示速度和剩余任务。编辑器正文保持素底。 |
| 容器列表、仪表盘、日志 | 仪表盘沿用状态色，CPU 和内存各自有名字和数值；日志、搜索命中、当前命中及跟随状态分别配色。 |
| 批量命令、上传、执行结果、历史 | 分组树和结果区沿用相同的选中态；运行中显示琥珀进度，失败行保留错误文本及重试操作。 |
| 运维工具、磁盘分析、服务管理 | 工具卡使用小幅线稿；扫描时旋转星形指示器；磁盘排行、下钻、服务控制保持紧凑。 |
| 分组、预设路径和命令 | 色点与主题选中底分开，拖动时只高亮当前项和落点；长命令仍可复制。 |
| 设置、安全、权限、版本更新 | 横向标签使用票签；授权框突出服务器名和具体动作，删除使用危险色。更新记录正文采用素底与清晰的 Markdown 标题层级。 |
| 公共浮层与状态 | 下拉、弹窗、通知、提示、空态、骨架屏、禁用态和键盘焦点统一适配。空态插画仅在有足够空间时出现。 |

## 动效节奏

- 悬停和选中渐变约 140ms，按下轻微收缩。排序沿用现有位移动画，避免叠加第二次位移。
- 上传完成时任务卡角标亮起约 350ms；失败用静态警示标记和可复制的错误内容。
- CPU、内存或磁盘告警沿用 2.8 秒柔和呼吸。系统启用减少动态效果时用静态描边。
- 终端输入、日志追加和监控采样过程中维持静态背景；角色表情只随任务状态切换。

## 实施顺序与验收

1. 在现有主题注册表增加 sakura，新增样式限定在 html[data-theme="sakura"]。角色资源只在该主题激活时加载。
2. 先接入总览、SSH 和文件传输。图表、终端使用各自的主题适配入口；复用现有主题持久化机制和锁屏加载顺序。
3. 扩展到表中其余页面和挂载到 body 的弹层。动画独立命名，切换主题或关闭页面时清理主题专属状态。
4. 在最小窗口 760×480、常规窗口及最大化下检查遮挡、长文本、对比度和键盘焦点。打开终端、日志、图表和任务浮层时依次切换四种主题，核对旧主题配色、输入、滚动位置及进行中的任务。

## SSH 终端 · 星铃接班分镜

动效跟随现有接管会话的状态，并绑定对应终端标签。状态牌复用停止按钮、当前轮次和暂停提示，避开右上角缩放控件。字符区保持夜紫素底。

| 时刻 | 画面与动作 |
| --- | --- |
| 选择接管模式，尚未开始 | 标签边显示一枚静态空心铃铛，提示「接管待命」。 |
| 开始执行 | 约 320ms 内，小头像戴好耳机，两颗星点沿终端上边缘向两端点亮，随后停在角落。状态牌显示「AI 接管中 · 2/8」或「AI 正在执行」，旁边保留「停止」。 |
| 执行持续 | 头像旁的通讯灯缓慢呼吸。新一轮开始只更新轮数；命令回显、日志追加或切回标签均不重播入场动画。 |
| 暂停，等待人工介入 | 通讯灯变成静态琥珀色，星铃抬起一只耳罩，显示问号。提示沿用实际原因「需要你输入」「需要你退出程序」「可能卡住了」，并保留对应的继续操作。 |
| 正常结束 | 星铃点头，薄荷绿对勾亮起约 350ms，状态牌淡出。 |
| 手动停止或执行失败 | 停止时收起耳机并显示「已停止」；失败时显示红色警示和实际错误。两者使用独立于成功的反馈。 |

后台终端只在自己的标签上保留状态标记。紧急停止沿用连按三次 Esc。装饰不捕获鼠标和键盘；系统减少动态效果时，使用静态头像、图标和文字。切出星铃主题时恢复原主题接管外观，当前会话继续运行。
