# 终端快捷侧边栏 + 多终端同步操作 设计方案

## 一、需求拆解

### A. 右侧快捷面板
1. 终端页右侧边缘有**展开按钮**，点击后出现右侧边栏
2. 边栏上=**预设命令**（按类型筛选，默认「系统」），下=**预设路径**
3. 点击某条命令 → 命令文本被**键入到当前终端**（不自动执行，用户自己按回车）
4. 点击某条路径右侧的**跳转按钮** → 终端被 `cd` 到该路径
5. 命令区、路径区各有一个 **`+` 小按钮**，用于新增
6. 列表某行**右键** → 编辑 / 删除

### B. 多终端同步操作
7. 边栏最上方有**「同步操作」**按钮
8. 开启后，已打开终端自动排成 **2×2 视图**：
   - ≤4 个：2 列网格，n=1 占整幅、n=2 左右各半、n=3/4 自然的 2×2 布局
   - >4 个：外层滚动，**每个区块仍固定占 1/4 大小**（不因滚动而缩小）
9. 开启同步后：在任一终端输入的命令会**同步键入到所有已打开终端**
10. 点右侧快捷命令 / 路径跳转，也同样**同步到所有已打开终端**

## 二、可复用的现成能力（本次尽量不新增后端）

| 能力 | 现状 | 复用于 |
|---|---|---|
| 预设命令 CRUD | `ListPresetCommands / SavePresetCommand / DeletePresetCommand`（`group.go`） | 侧边栏命令区 + 新增/编辑/删除 |
| 预设路径 CRUD | `ListPresetPaths / SavePresetPath / DeletePresetPath` | 侧边栏路径区 |
| 前端封装 | `api.listPresetCommands/savePresetCommand/deletePresetCommand/listPresetPaths/savePresetPath/deletePresetPath`（已存在） | 直接调用 |
| 终端会话写入 | `TerminalWrite(id, data)`（写 SSH stdin） | 键入命令、cd、同步广播 |
| 终端尺寸 | `TerminalResize(id, cols, rows)` | 进入/退出 2×2 后重新 fit 并上报 |
| 分类 | `PresetCommand.Category` 自由文本，预设页候选为 `系统/网络/服务/磁盘/日志/其他` | 侧边栏筛选 chips |

**结论：本次前端为主，后端只加 2 个小方法。**

### 需要新增的后端方法（`prj/terminal.go`）

```go
// TerminalPwd 在指定终端会话中执行 pwd，返回当前工作目录（用于「新增路径」预填）
func (a *App) TerminalPwd(id string) (string, error)

// TerminalWriteMany 向多个终端批量写入（可选；前端循环调用也可，
// 但一次调用能减少 IPC 往返，同步广播时更稳）
func (a *App) TerminalWriteMany(ids []string, data string) error
```

实现要点：
- 二者都复用 `TerminalSession`，注意 `terminalMu` → `ts.mu` 的加锁顺序与现有方法一致
- `TerminalPwd` 用 `sess.CombinedOutput("pwd")` 会与交互式 shell 抢占同一会话通道，**不可行**；
  改为在终端输入 `pwd\n` 再读输出同样污染屏幕。因此实现方式为：
  **解析远端 shell 提示符不可靠 → 改为对同一 SSH client 新开一个短会话执行 `pwd` + `cd` 无效**。
  ⇒ 最终方案：`TerminalPwd` 用**同一 sshx.Client 新建独立 session 执行 `pwd`**，
  但独立 session 的 cwd 与被监控会话不同（新会话总是落到 home）。
  ⇒ **取舍**：新增路径时**不预填远端 pwd**，默认预填 `/`，用户可改；
  若要精确当前目录，在 3.x 版本用「终端输出尾部解析提示符」实现（见 §六 不做项）。
- `TerminalWriteMany` 逐个 `stdin.Write`，单个失败不影响其他（返回汇总错误）。

## 三、界面设计

### 3.1 整体布局

```
┌──────────────────────────────────────────────┬───────────────┐
│ [标签栏: 服务器A ×] [服务器B ×]  [+]          │  ★ 同步操作    │
├──────────────────────────────────────────────┤               │
│                                              │ 预设命令  [系统▾]│
│            终端区域（单窗口 / 2×2）            │ ┌───────────┐ │
│                                              │ │ 查看磁盘   │ │
│                                              │ │ 查看内存   │ │
│                                              │ └───────────┘ │
│                                              │        [+]    │
│                                              ├───────────────┤
│                                              │ 预设路径       │
│                                              │ ┌───────────┐ │
│                                              │ │ /var/log 跳 │ │
│                                              │ └───────────┘ │
│                                              │        [+]    │
└──────────────────────────────────────────────┴───────────────┘
     ↑ 未展开时右边缘只留一个细窄的展开条（贴着屏幕右侧）
```

- **展开/收起**：终端区右边缘放一个 14px 宽的竖条按钮（图标 `DArrowLeft/DArrowRight`），
  悬浮时高亮；展开后侧栏宽 `300px`（≥1400px 窗口用 340px），收起时连竖条一起只占 14px。
- 侧栏整体可折叠状态用 `localStorage`（键 `xx1.terminal.sidebar`）记忆。

### 3.2 侧栏三个区域

| 区域 | 内容 |
|---|---|
| 顶部操作条 | `★ 同步操作` 开关按钮（激活态高亮 + 显示已同步终端数）+ 分类筛选 chips + 刷新 |
| 预设命令区 | 列表项：名称 + 命令（等宽小字，超长省略）+ 右侧小 `+` 表头按钮；行悬浮时右侧出现「插入」图标 |
| 预设路径区 | 列表项：名称 + 路径（等宽小字）+ 右侧「跳转」按钮；表头小 `+` |

- 两区各自独立滚动（`flex: 1 1 0` + `min-height: 120px`），避免长列表把另一半挤出屏幕。
- 每区表头显示条数（`预设命令 · 12`），空列表显示引导文案「暂无命令，点 + 添加」。
- 底部固定一行小字入口：`管理预设` → 跳 `/presets`（完整管理在预设页，侧栏只做便捷操作）。

### 3.3 点击行为（关键交互约定）

| 操作 | 行为 |
|---|---|
| 点命令行主体 | 将该命令**键入当前终端**（`TerminalWrite`），**不追加回车**，用户自己按回车 → 避免误执行 |
| 点命令行「插入」图标 | 同上（与点行主体一致，图标只是可发现性提示） |
| 点路径行「跳转」 | 键入 `cd '<path>'\n` 并**立即执行**（跳转本身就是意图） |
| 点 `+`（命令/路径） | 打开编辑对话框（新增模式），命令默认分类=当前筛选类型 |
| 行右键 | 弹出菜单：`编辑器插入` / `编辑` / `删除`（删除二次确认） |

- 命令插入只对**当前激活终端**生效；**开启同步时对所有终端生效**。
- 多行命令：整体写入（含换行），行为与粘贴一致。
- 若当前没有激活终端 → `ElMessage.warning('请先打开一个终端')`。

### 3.4 同步操作的 2×2 视图

- 开启同步：
  - 终端区容器切到 `sync` 模式，`display: grid; grid-template-columns: repeat(2, minmax(0, 1fr));`
  - **区块高度固定**：`grid-auto-rows: calc(50% - 4px)`（配合 `gap: 8px`），
    这样 >4 个终端时总高超出容器 → 外层出现纵向滚动条，**每个区块仍是 1/4 大小**（符合需求 8）
  - 区块带边框 + 服务器名角标，便于分辨
  - 切换后 `nextTick` → 对所有终端 `fit.fit()` + `TerminalResize(id, cols, rows)`
- 关闭同步：恢复单窗口叠层布局（当前实现：`.term-pane` 绝对定位 + `v-show` 激活那个），
  同样需要重新 fit + resize（尺寸变化在 xterm 里不会自动感知）
- n=1 时网格只有一格 → 占满整幅；n=2 自然左右各半；n=3 左上、右上、左下（右下留空）

### 3.5 同步输入

- `term.onData(data)` 里：若**同步开启**，则对该 `data` 广播到所有终端
  （含发起者自己也写一次也可以，但更稳妥的做法是：发起者由 xterm 本地回显 + SSH 回显，
  因此**只写给其他终端**，避免发起者重复输入）。
- 广播实现走 `TerminalWriteMany(ids, data)`，一次 IPC。
- 同步开启后，**发起者终端的输入仍照常走原来单路**，保证不丢字符。
- 快捷命令 / 路径跳转：走同一个「目标集合 = 同步开启时全部终端，否则当前终端」。

## 五、边界情况与失败模式

| 场景 | 处理 |
|---|---|
| 没有打开的终端 | 快捷命令/路径点击提示"请先打开一个终端"；同步按钮禁用（或允许开但无作用并提示） |
| 终端会话已断开（`terminal:close`） | 该标签标记"已断开"，广播时跳过并计数提示 |
| 同步终端数量很多（如 12 个） | 广播一次性写入，不做并发限制（写入是内存 + 已有 SSH 管道）；UI 上显示"已同步 12 个终端" |
| 命令含 `\n` | 整体写入，等效粘贴；如需只插入不执行，用户可自行删尾换行（默认不追加） |
| 命令含中文/引号 | 直接写入 stdin，不经过 shell 解析，无需转义 |
| 路径含空格/引号 | `cd` 命令对路径做单引号转义（`'` → `'\''`），避免命令注入与空格截断 |
| 一个终端 fit 失败（DOM 未就绪） | try/catch 跳过该终端，不影响其他 |
| 切换同步模式时正在输出 | xterm 缓冲不受影响；只是尺寸变化，重绘由 fit 触发 |
| 侧栏展开导致终端变窄 | 展开/收起后同样触发一次 fit + resize（否则远端认为仍是旧宽度，换行错乱） |
| 分类筛选后新增 | 新增项默认归入当前筛选的分类，保证新增后立刻可见 |
| 预设被删除时的可操作性 | 右键删除前二次确认，文案含名称 |

## 六、明确不做（本期）

1. **不预填远端当前目录**：交互式 shell 的 cwd 无法在 SSH 协议层安全取得
   （`CombinedOutput` 会抢占会话通道、读输出解析提示符不可靠），
   新增路径时默认预填 `/`，用户自行修改。
2. **不做同步的"分屏独立缩放"**：2×2 每格等大，不支持拖拽调整格子大小。
3. **不做把快捷面板做成可拖拽宽度**：固定 300/340px 两档。
4. **不做终端内的命令历史/自动补全**（用户未提出，且需要解析远端 shell）。

## 八、验收清单

1. 未打开终端时：标签栏高度正常，右边缘展开条可点，侧栏可开；点命令提示"请先打开一个终端"。
2. 打开 1 个终端 → 展开侧栏 → 点「系统」分类下某命令 → 终端出现该命令文本且**未执行**；按回车执行成功。
3. 点某路径的「跳转」 → 终端执行 `cd`，`pwd` 结果与预设一致（含含空格的路径用例）。
4. 命令区 `+` → 对话框默认分类=当前筛选 → 保存后新命令出现在列表中（无需刷新）。
5. 路径区 `+` → 保存后出现在列表。
6. 任一行右键 → 编辑（回填原值）/删除（二次确认、删后列表消失、预设页同步消失）。
7. 开 3 个终端 → 点「同步操作」 → 变成 2×2（右下空）→ 在左上输入 `echo hi` 回车 → 三个终端都执行。
8. 开 6 个终端 → 同步 → 出现滚动条、每格仍为 1/4 大小 → 滚动到第二屏能看到后 2 个。
9. 同步开启时点快捷命令/路径 → 所有终端都出现同样命令/都 cd 成功。
10. 关闭同步 → 回到单窗口，且当前终端尺寸正确（输入长命令行换行正常，无错位）。
11. 展开/收起侧栏后，终端列宽自适应（`stty size`/`tput cols` 输出与窗口一致）。
12. 主题切换（浅/深/赛博）下侧栏与同步网格样式正常。
